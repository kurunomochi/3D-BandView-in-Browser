# Blender 工程上传扩容到 1 GiB：给 Rust 博客加上分片上传

前几天，我给博客作品集加上了 Blender 工程上传和网页 3D 预览。第一版的模型文件上限是 50 MiB，简单场景够用，但把贴图打包进工程后，很容易超过这个大小。这次把 .blend 上传上限提高到 1 GiB，也就是 1024 MiB，并把上传方式改成分片传输。

## 现在能传多大的文件

- Blender 工程 .blend：最大 1 GiB（1024 MiB）。
- 直接上传的 GLB：仍然最大 50 MiB。
- Blender 转换生成的网页 GLB：仍然最大 100 MiB。

这几个数字对应不同环节。提高原始工程的上传上限，并不意味着访客需要下载一个 1 GiB 的网页模型，也不意味着这台服务器一定能转换所有 1 GiB 工程。

## 为什么不只修改一个大小常量

原来的接口会把单次上传的模型读入内存，再保存到磁盘。对小文件很直接，但服务器只有约 2 GB 内存，如果照搬这种方式接收 1 GB 工程，就会让上传本身占用过多内存。

另外，网站经过反向代理和 CDN，单次 HTTP 请求还有独立的大小限制。只把 Rust 后端的数字调大，文件可能在到达后端之前就被拒绝。

因此，这次让浏览器使用 File.slice() 把文件切成最多 8 MiB 的小块，按顺序上传。服务器接收一块就写到非公开的临时文件中，不把完整工程放进一个大内存缓冲区。

## 上传过程怎样工作

第一步，浏览器发送文件格式和总大小，服务器在验证管理员身份、大小限制与任务并发后创建上传会话，返回任务 ID 和分片大小。

第二步，浏览器按偏移量发送分片。服务器核对分片顺序与剩余大小，写入磁盘后才返回已经接收的字节数。后台据此显示上传百分比和已上传容量。

第三步，所有分片上传完成后，浏览器发送完成请求。服务器检查文件是否完整，再进入已有的 Blender 转换流程。最后，等后台提示模型准备完成，保存作品即可发布。

接口分成 POST /api/model-upload-sessions、PUT /api/model-upload-sessions/{id}?offset=... 和 POST /api/model-upload-sessions/{id}/complete。原来的单请求上传接口仍然保留，限制仍为 50 MiB，大工程需要使用新的分片接口。

## 网络重试不能把文件拼坏

一种容易忽略的情况是：服务器已经收到了分片，但确认响应在网络中丢失。浏览器会以为上传失败，再发一次相同分片。如果服务端只是一直追加数据，文件就会多出一段重复内容。

现在重试会带上原来的偏移量。服务器遇到已经接收过的区域，会比较磁盘里的内容：相同就确认成功，不再追加；不同则报错。完成请求也可以重复提交，避免因为响应丢失而重复启动转换任务。

浏览器对网络错误和服务器临时错误最多重试两次。身份验证、格式错误等明确的客户端错误不会盲目重试。

## 取消与临时文件

上传期间新增了「取消上传」按钮。取消会停止客户端请求，并请求服务器清理当前上传的临时目录、释放任务名额，不会修改原来的作品。

如果页面直接关闭，未完成的上传会在闲置约 30 分钟后过期清理；单个上传会话总时长最多 6 小时。当前还不支持刷新页面或服务重启后的断点续传。服务器意外退出留下的临时目录，需要管理员检查清理。

## 这次实际测试了什么

上线前，使用生成的传输测试数据，经服务器本机 HTTP 接口完整上传了 1 GiB，并比较了文件大小和 SHA-256，结果一致。测试包含重复发送分片，确认不会产生重复数据。上传期间 Rust 后端进程的峰值常驻内存约为 34 MiB；这个数字描述的是本次上传测试，不是 Blender 转换时的内存需求。

上线后，又通过正式 HTTPS 域名完整上传了 112 MiB 测试数据，验证分片能够经过公网代理，文件哈希匹配，取消后测试文件被清理。1 GiB 测试针对上传传输，没有把填充测试数据当作真实工程进行转换。

另外使用小型真实 .blend 工程验证了分片上传后的自动转换、模型访问和原文件隔离。代码回归测试覆盖登录鉴权、大小边界、错误偏移、重复分片、提前完成、取消清理及旧功能，Rust 静态检查也通过。上线前后，已有文章和作品保持不变。

## 能上传，不代表一定能转换

这台服务器的转换进程仍然限制为单任务、单线程，内存地址空间上限 1.5 GiB，转换等待超时 150 秒。大量贴图、复杂修改器和高面数场景，即使文件上传成功，也可能超过转换能力。

这次先解决「工程传不上去」的问题。遇到转换失败，可以在本机减少面数和贴图尺寸、应用必要的修改器，再导出适合网页展示的 GLB。以后如果需要更复杂的工程，还要继续考虑本机转换、独立转换机器或更高配置的服务，不能仅靠继续调高上传上限。

## 使用入口与代码

进入作品工作室，新建或编辑作品，在「3D 交互模型」区域选择工程。上传期间保持页面打开，等转换完成后再保存作品。若还看到旧的 50 MiB 提示，刷新后台页面即可。
